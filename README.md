# My Manhwa Tracker — GitHub Pages PWA

## Files
- `index.html` — the tracker
- `manifest.json` — app installation metadata
- `sw.js` — offline/service-worker support

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload all three files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose your main branch and `/ (root)`, then save.
6. Open the generated GitHub Pages URL using Chrome or another supported browser.
7. Use **Install App** when the browser offers installation.

The tracker stores entries locally in the browser, so the data stays on that device/browser unless you add cloud synchronization separately.
